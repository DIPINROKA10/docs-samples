# Documentation samples

This site is a small **docs-as-code** portfolio by **Dipin Roka**. Every page lives in Git,
is written in Markdown, and is published through GitHub Actions to GitHub Pages — the same
workflow a technical writer uses for product documentation.

## Sample projects

- **[ASTRA overview](astra/overview.md)** — crime-intelligence dashboard for a police datathon.
- **[CarbonTrace overview](carbontrace/overview.md)** — carbon-footprint tracker for sustainability
  awareness.
- **[How to register for an event on FestNest](festnest-register-user-guide.md)** — end-user guide
  for a product (FestNest).

## What each sample demonstrates

| Skill | Where it shows |
|---|---|
| Markdown + structure | every page |
| YAML configuration | `mkdocs.yml`, the GitHub Actions workflow |
| Git / CI / Pages | `.github/workflows/pages.yml` |
| Plain-English explanation | FestNest user guide |
| Schema-style field docs | `carbontrace/setup.md` data model |
| Changelog discipline | `CHANGELOG.md` |
